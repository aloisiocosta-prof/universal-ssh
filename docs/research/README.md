# Research protocol

Universal SSH treats engineering outputs as research evidence.

## Evidence chain

Evidence → Requirement → Test → Implementation → Measurement → Analysis → Documentation

Every research question (RQ) must identify measurable variables, the commit under evaluation, the procedure used to collect data, threats to validity, and the evidence artifacts produced by CI.

Use the templates under `docs/research/templates/`. Do not add bibliographic claims without a verified source and stable identifier (prefer DOI for scholarly literature).
